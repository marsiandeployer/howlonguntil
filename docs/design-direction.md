# Design direction

The user selected concept 04: a calm blue editorial desk with pale paper, deep navy typography, a restrained cyan time underline, soft daylight, and quiet human context. The small promo and marquee have been uploaded and read back. This is the store-marketing identity; it does not replace the utility UI palette currently implemented.

The working extension is an Operate surface: quiet, readable, compact, countdown-first. Its implemented utility UI uses warm-white surfaces, deep ink, restrained violet underline, clear focus and numeric alignment. Keep original page text intact. Do not introduce decorative gradients, artificial world clocks, dashboards, mock activity or inactive controls that look usable. “Reminders · Pro — Soon” is visibly disabled.

Keep store materials in concept 04's blue editorial direction. The packaged utility UI remains as built unless separately changed.
