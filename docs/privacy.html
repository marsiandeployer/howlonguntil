How Long Until: privacy

Last updated: October 21, 2026.

How Long Until finds time expressions in pages you permit it to access and shows a countdown and your local time. This processing takes place on your device.

Page content stays on your device

The extension reads page text in memory to identify dates, times and time zones. It does not save page text, browsing history, detected events or page URLs to a server. It does not send page content to the developer or any third party.

What is saved

Your enable/disable choice, disabled website origins, preferred time zone, clock format and time-zone abbreviation overrides are stored in Chrome's local extension storage. These preferences are not synced by this extension or sent to a server. You can remove them by uninstalling the extension or clearing its local data.

No remote code or analytics

All executable code, dependencies, styles and images used by the extension are included in its installed package. It does not download remote scripts, fonts or executable updates outside Chrome's extension update mechanism. It has no analytics, advertising, tracking pixels or accounts.

Website access

The extension requests access to ordinary HTTP and HTTPS websites when you enable highlighting. This is needed to locate time expressions on the pages you read. You can disable highlighting globally or on a particular website and revoke website access through Chrome's extension settings.

Future reminders

“Reminders · Pro — Soon” identifies a planned paid feature. This version does not provide reminders, accept payments or request permission to display system notifications.

Open source and questions

Read the source code or ask a question in the public repository. Any future change in data handling will be reflected in this policy and the corresponding extension version.
