# How Long Until store artwork

Both files are illustrative promotional artwork, not product screenshots. They were generated with the built-in image generation tool using the user-selected `store/creatives/concept-04.png` as the visual reference. The final files preserve its pale paper, calm blue desk, deep navy type, cyan underline, and soft daylight.

- `promo-small.png`: 440x280 RGB PNG, store promo tile.
- `promo-marquee.png`: 1400x560 RGB PNG, wide marquee artwork.
- `source/`: unmodified generated PNGs before delivery resize/conversion.
- `prompts/`: exact generation prompts for each asset; each final PNG also embeds its prompt and selected concept reference in iTXt metadata.

The example is internally consistent for a UTC+3 viewer: 18:00 UTC is 21:00 local and 2h15m away. No security, reminder, rating, or endorsement claims are shown.
